Java Script:
============

What is JavaScript:
-----------------
JavaScript is a cross-platform, object-oriented scripting language used to create interactive websites.

Who Invented: Brendan Eich
------------

when Invented: 1995.
--------------

why JavaScript is created:
--------------------------
In the early days of the web, websites were static (they only displayed information). There was no interaction on webpages.

Netscape wanted a language that could:
. Make webpages interactive
. Allow form validation before sending data to the server
. Respond to user actions like clicks
. Run directly inside the browser

So Brendan Eich created JavaScript in just about 10 days to add these interactive features to websites.

What JavaScript Can Do:
----------------------
JavaScript adds behavior and functionality to a webpage.

For example it can:
. Create animations
. Handle button clicks
. Show popup messages
. Validate form inputs
. Update page content without reloading
. Build interactive menus and sliders



Where JavaScript Runs
=====================
1. Client-side (Browser)
-----------------------
Runs inside a web browser like Chrome or Edge.
It interacts with the DOM (Document Object Model) to change the webpage.

Example:
. Change text
. Hide/show elements
. Respond to clicks

2. Server-side
--------------
JavaScript can also run on servers using
Node.js.

This allows JavaScript to:
. Connect to databases
. Handle user requests
. Build full backend systems
. Enable real-time apps (chat apps, collaboration tools)

What is JavaScript?
-------------------
. JavaScript is a high-level, interpreted programming language primarily used to make webpages interactive and dynamic
. initially websites were static and could only display content.
. Js allows webpages to respond to user actions and update content and server.
. JS is Synchronous in Nature but it supports async features by using different API's 
. Initially before node.js javascript is used as client side Scripting(front-end) 
  but after node.js we can run javascript at Server side too(backend)
. Node.js is a runtime Environment to run Js outside of the browser.


Features of JavaScript:
----------------------
1. JavaScript is an object based and Object Oriented programming language.
    -->Object based(in Js Objects are having inbuilt methods)
    -->Object Oriented Programming(It contains OOPs concepts like polymorphism, encapsulation, abstraction, inheritence)
2. JavaScript is Platform in-dependent Programming language
    -->you can run on any browser because each browser has their own js engine

    Browser                   JS-engine
    -------                    --------
    Chrome                    v8(version-8)
    MS internet edge          old (chekra)
                              new (V8)
    safari                    JavaScriptCore
    Mojila Firefox            SpiderMonkey
3. JavaScript ia a loosely typed Programming language
    --> no need to give semicolon
4. JavaScript is a dynamic typed
    --> Datatype of variable is decided in run time
    --> we don't need to give datatype explicitly
5. JavaScript is Case sensitive
    --> Both Uppercase and lowercase words are treated different
6. JavaScript is Interpreted programming language
7. JavaScript is a Synchronous in nature / Single thread system
    --> Only one call Stack is present in javascript
8. JavaScript uses Just-in-time compiler 
    -->used to check for syntax
9. It is a client side and server side(node.js) programming language
